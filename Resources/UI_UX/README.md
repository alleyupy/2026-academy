## 🎯 UI vs UX (Quick Definition)

**UI (User Interface)** = What users **see** (buttons, colors, layout, typography)  
**UX (User Experience)** = What users **feel** (kemudahan, navigasi, kepuasan)

**it's like🤔..**: UI = the design of a car (paint, body kit)  | UX = What's it like to drive?. **Both matter!**
